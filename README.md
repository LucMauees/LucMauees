##  Projetos em destaque

###  Classroom Assistant
Aplicação **Python/FastAPI** que integra **Google Classroom**, **Google Drive** e a **API da Anthropic** para gerar planos de estudo personalizados a partir dos materiais dos professores.
- OAuth 2.0 com Google, listagem de cursos/materiais via Classroom API
- Download de PDFs via Drive API e extração com `pdfplumber`
- Geração dos planos de estudo com LLM — fluxo validado ponta a ponta

###  Albion Online Market Tools
Suíte em **React** para análise de mercado e lucro de crafting no Albion Online, consumindo a **API do Albion Online Data Project**.
- **Merchant Terminal:** 8 variáveis de mercado, gráficos com Recharts, previsão de preço e custo de craft
- **Calculadora de culinária:** lucro por receita com presets de taxa de retorno (base, foco, cidade bônus)
- **Mercado de comidas:** 52 comidas em 7 cidades, preços ao vivo e abas por cidade
- Fallback de importação manual de JSON para ambientes com CSP restritivo

###  Análise de dados de Zika (SINAN 2018–2026)
Projeto acadêmico em **PostgreSQL 15**: schema com 9 tabelas, pipeline ETL, functions, triggers e views, previsão com **NeuralProphet** e clusterização **K-Means** (k=4, silhouette 0,82 sobre 427 municípios e 28.328 casos confirmados).

###  Laboratório Wazuh
Ambiente de **SIEM/XDR** em Docker para praticar detecção de malware, threat hunting, detecção de vulnerabilidades, automação e resposta a incidentes — já com agente registrado e FIM funcionando.

###  App de aluguel de carros
Projeto próprio de aplicativo para aluguel de veículos.

###  Machine Learning
- **Classificador de lesões de pele (ISIC 2019)** com CNN DenseNet-121
- **Previsão de séries temporais com LSTM** (temperaturas diárias de Melbourne, 7 configurações de hiperparâmetros)
- Regressão linear múltipla (UCI Auto MPG)
- TCC em andamento: **deep learning para diagnóstico auxiliado por computador (CAD) em imagens médicas**

###  Analisador de faturas
